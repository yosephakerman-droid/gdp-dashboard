# ניתוח פיננסי אישי

אפליקציית Streamlit שמקבלת את הנתונים הפיננסיים שלך ומציגה:

- **סקירה** – שווי נקי, כמה נזיל, הכנסה/הוצאה חודשית ממוצעת ושיעור חיסכון.
- **הכנסות מול הוצאות** – לפי חודש, תזרים נטו, נטו מצטבר ומקורות הכנסה.
- **פילוחים** – הוצאות לפי קטגוריה, מגמה לכל קטגוריה, קבועות מול משתנות, לפי חשבון, חיובים חוזרים ובתי עסק.
- **נכסים וחיסכון** – פנסיה, קרן השתלמות, גמל, השקעות, פיקדונות והלוואות; דמי ניהול שנתיים ותחזית צבירה עד הפרישה.
- **המלצות** – כללים פשוטים: קרן חירום, שיעור חיסכון, דמי ניהול, הלוואות יקרות, קפיצות בהוצאות, מנויים, נזילות קרן השתלמות.
- **נתונים ועריכה** – תיקון קטגוריות ועריכת נכסים ישירות באפליקציה, והורדת התנועות המסווגות.

ההמלצות אינן ייעוץ השקעות, פנסיוני או מס. הספים בהן הם ברירות מחדל שניתן לשנות בסרגל הצדדי.

## הרצה

```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

בהפעלה הראשונה בחר "נתוני דוגמה" כדי לראות את המערכת על נתונים פיקטיביים.

## אילו קבצים להעלות

| קובץ | מה צריך בו |
|---|---|
| עו"ש | תאריך, תיאור, וסכום (שלילי = הוצאה) **או** עמודות חובה/זכות |
| כרטיס אשראי | תאריך, שם בית העסק, סכום חיוב (חיובי = הוצאה, כמו בקובצי חברות האשראי) |
| נכסים | שם, סוג, גוף מנהל, יתרה, הפקדה חודשית, דמי ניהול מצבירה %, דמי ניהול מהפקדה %, תשואה/ריבית %, תאריך נזילות |

- CSV או Excel. שורות כותרת בראש הקובץ (כמו בייצוא מהבנק) מדולגות אוטומטית.
- שמות עמודות נפוצים בעברית מזוהים (למשל "תאריך עסקה", "שם בית העסק", "סכום חיוב", "חובה", "זכות"). לא נבדק מול כל פורמט ייצוא של כל בנק; אם קובץ לא נקלט, שנה את הכותרות לפי התבנית שבסרגל הצדדי.
- סוגי נכסים: `עו"ש`, `פיקדון/חיסכון`, `השקעות`, `קרן השתלמות`, `פנסיה`, `קופת גמל`, `הלוואה`. בהלוואה, "יתרה" היא יתרת החוב ו"תשואה/ריבית" היא הריבית.
- אם מעלים גם עו"ש וגם פירוט אשראי, החיוב החודשי של הכרטיס בעו"ש לא נספר שוב (כדי לא לספור פעמיים).
- העברות לחיסכון/השקעות נספרות כחיסכון, לא כהוצאה. זיכויים מקטינים את ההוצאה בקטגוריה שלהם.

## מבנה

- `streamlit_app.py` – הממשק.
- `finance/loader.py` – קריאת קבצים וזיהוי עמודות.
- `finance/analysis.py` – סיווג, תזרים, פילוחים, נכסים ותחזיות.
- `finance/recommendations.py` – כללי ההמלצות.
- `finance/schema.py` – קטגוריות ומילות מפתח לסיווג (אפשר להוסיף שם בתי עסק).
- `scripts/make_sample_data.py` – יוצר את נתוני הדוגמה ב-`data/`.

בדיקות: `pip install pytest && pytest`
